# Fyp-phase2

A modern web application built with Vite, React, TypeScript, Tailwind CSS, and shadcn-ui.

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn-ui

## Getting Started

### Prerequisites

- Node.js (recommended via [nvm](https://github.com/nvm-sh/nvm#installing-and-updating))
- npm

### Installation

```bash
git clone https://github.com/sreeks7675/Fyp-phase2.git
cd Fyp-phase2
npm install
```

### Run the App

```bash
npm run dev
```

The app will start in development mode with hot reloading.

## Available Scripts

- `npm run dev` — Start development server
- `npm run build` — Build for production
- `npm run preview` — Preview production build locally

## Editing the Project

Build the app for production:


Then deploy the generated output using your preferred hosting platform.
